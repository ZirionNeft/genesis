## Определения и допуски

`MutationRules` создаётся как immutable snapshot с собственным ID/версией
и точной ссылкой на frozen `GeneticsRuleset`. Для каждой из четырёх категорий
обязателен явный набор допустимых локусов, включая явно пустой набор.
Глобальная привязка категории к локусу не зашита в enum: покров, например,
может иметь косметический или физиологический эффект по определению контента.

`MutationDefinition` содержит namespaced ID, категорию, локус, целевой аллель,
класс эффекта и непустой whitelist исходных неупорядоченных пар этого локуса.
Допуск определяется по уже унаследованной паре. Условий по другим локусам
пока нет; полный набор контентных ограничений D06 ещё предстоит проверить.

Все аллели цели и исходных пар должны существовать на указанном локусе
в полном genetics ruleset. Новая мутация не регистрирует аллель во время расчёта.
Запрещены повтор ID, алиас того же `(category, locus, targetAllele)`, неверный
локус/категория и исходная пара из двух копий самой цели (изменения не было бы).
Одна уже существующая копия целевого аллеля допустима: меняется вторая копия.
Регистрация/namespace внешних providers и стабильный Public API здесь не реализованы.

Косметический вариант имеет только класс COSMETIC. Остальные варианты имеют
BENEFICIAL, TRADEOFF или HARMFUL. Это метаданные генератора, а не вычисление
пользы для каждой ситуации; реальные эффекты и цена задаются отдельно в фенотипе
и игровых умениях. Объявление TRADEOFF само по себе не проверяет баланс.

## Вероятности

`MutationPolicy` хранит defensive immutable maps и явную политику SKIP.
Вероятности конечны и входят в [0,1]. Все категории обязательны, их сумма
не выше 1; остаток — отсутствие новой мутации. Для некосметического класса
обязательны три вероятности с суммой ровно 1. Проверки и границы интервалов
используют BigDecimal из десятичных представлений double, без epsilon.

Начальные, настраиваемые через чистый API значения GDD:

| Исход | Интервал draw ∈ [0,1) | Вероятность |
| --- | --- | --- |
| Без новой мутации | [0, 0.92) | 92% |
| COSMETIC | [0.92, 0.96) | 4% |
| PHYSIOLOGICAL | [0.96, 0.985) | 2.5% |
| BEHAVIORAL_SENSORY | [0.985, 0.995) | 1% |
| ARCANE | [0.995, 1) | 0.5% |

Некосметический класс: BENEFICIAL [0,0.3), TRADEOFF [0.3,0.7), HARMFUL [0.7,1).
Это предварительные веса §9.2; сам файл игровой конфигурации ещё не реализован.

## Алгоритм и пропуск

`MutationRules.ALGORITHM_VERSION=1`, вход — уже унаследованный геном допустимой
успешной попытки, immutable policy и выделенный `MutationRandom`.

1. Валидировать весь геном и его точный genetics ruleset до первого RNG.
2. Один draw категории, включая отсутствие мутации. Для некосметической
   категории — ещё один draw класса эффекта; для косметической его нет.
3. Собрать определения выбранной категории/класса с подходящей исходной парой.
4. Если определения есть, равномерно выбрать локус среди доступных в порядке
   `Locus`, затем цель среди определений этого локуса в порядке `ContentId`.
   Большее число целей одного локуса не повышает шанс выбрать сам локус.
5. Равномерно выбрать одну из копий, отличных от цели, в порядке 0/1 исходной
   канонической пары; заменить её, канонизировать результат и валидировать геном.

Возвращается `Unchanged`, `Skipped` или `Mutated`. `Change` содержит ID,
категорию/класс, локус, индекс исходной копии и аллели до/после. Индекс относится
к канонической паре **до** изменения, а не к родителю или позиции после сортировки.
Исходный геном не меняется; другие 11 локусов сохраняются.

Внутренняя политика **SKIP** выбрана 16.10.2026: при недоступном выходе сохранить
наследованный геном и явно вернуть причину CATEGORY_UNAVAILABLE,
IMPACT_UNAVAILABLE или GENOTYPE_UNSUPPORTED. Нет повторного броска, нормализации
шансов на оставшийся контент или подмены генома. Для отсутствующей некосметической
категории draw класса всё равно выполняется до проверки доступности (контракт v1).
При пропусках фактическая доля изменённых потомков ниже 8%; полная доступность
должна обеспечиваться контентом, а не скрытой сменой вероятностей.

SKIP относится к недоступному новому варианту в известных правилах. Неизвестные
аллели/версии дают ошибку до RNG; отсутствие обязательного расширения по ADR-001
должен отклонять будущий workflow, а не трактовать как SKIP. Работа с opaque
payload реализована в [следующем GEN1-пакете](stage-1-genesis-code.md);
её подключение к полному workflow ещё предстоит.

Лимит — одна **новая** заменённая копия за вызов. Уже унаследованных мутантных
копий может быть несколько: они остаются обычными аллелями. Pure-метод не знает
birth ID; ровно один вызов после успешной попытки, идемпотентность и запрет
повторной мутации того же рождения обеспечит будущий workflow/этап 2A.

## Воспроизводимость

`SeededMutationRandom`: обычный Java Random с nextDouble/nextInt,
ID `genesis:mutation_java_random_lcg48_v1`, 48-битное состояние. Поток выделен
только для мутаций, не расходуется наследованием/успехом попытки/UI.
Общая схема получения разных seed из birth seed, их codec и сохранение
версий правил/снимка настроек остаются открытыми в D11/2A.

При применённой мутации после вероятностных draw всегда выполняются три
nextInt: локус, цель, копия, **включая bound=1**. При Skipped nextInt не вызывается,
при Unchanged используется только один nextDouble. Входные значения внедрённого
RNG проверяются; ошибочный RNG не может изменить исходный immutable-геном.

Фиксированный вектор seed 42 для синтетического профиля: физиологическая
категория 100%, классы 30/40/30, локусы MUSCLE/STAMINA, по одной цели класса
на локус, обе исходные копии a/a. Каждый результат рассчитан от исходного a/a:

```text
TRADEOFF   MUSCLE  0
BENEFICIAL MUSCLE  0
TRADEOFF   STAMINA 1
TRADEOFF   STAMINA 1
TRADEOFF   MUSCLE  1
BENEFICIAL MUSCLE  1
TRADEOFF   STAMINA 0
BENEFICIAL MUSCLE  1
HARMFUL    MUSCLE  0
TRADEOFF   MUSCLE  0
```

Вектор независимо рассчитан через LCG-формулы Java: начальное состояние
`(seed xor 0x5DEECE66D) mod 2^48`, шаг `(state*0x5DEECE66D+0xB) mod 2^48`;
nextDouble собирает 26+27 бит, bounded nextInt использует алгоритм Java.
Тест фиксирует также расход RNG на единственную цель.

92/4/2.5/1/0.5 и три условных некосметических класса 30/40/30. Для каждого

одна заменённая копия и разрешимость всех 12 экспрессий.

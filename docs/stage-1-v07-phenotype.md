## Определения и точные ссылки

[ExpressionRules](../src/main/java/dev/ifelse/zirion/genesis/core/phenotype/v2/ExpressionRules.java)
— immutable Core-таблицы, получаемые Java CatalogLoader из нормативных источников.
Они включены в `CatalogBundle` вместе со схемами генов и графом. Production Java
не содержит второй таблицы вариантов/эффектов или балансных defaults.
Прежние десять статов прототипа не используются новым семистатным расчётом.

Снимок закрепляет ID/version/SHA-256 expression, gene schema, graph и morphology,
а также ID/SHA-256 контентного каталога. При публикации проверяются совместимость
с bundle, все trait-гены и пары применимых семейств, ровно 12 исходных баз,
полные символические visual/utility-состояния и ARCANA/ELEMENT spell map.
HERITAGE не получает самостоятельных percent/flat-эффектов.

У каждого visual slot и utility-модификатора один источник среди генов.
Неоднозначная композиция, потерянное состояние в паре или неизвестная магическая
семантика дают отказ, даже если хеши пересчитаны. Текст формулы должен соответствовать
исполняемому контракту; значения clamp читаются из нормативного policy и сверяются
с config прежней проверкой mirrors.

## Семь генетических статов

[PhenotypeResolver](../src/main/java/dev/ifelse/zirion/genesis/core/phenotype/v2/PhenotypeResolver.java)
принимает историческую идентичность и геном. Сначала FormResolver проверяет
весь геном, точные ссылки и включение генетических линий в исторические корни.
Затем для каждого trait-гена выбирается одна зарегистрированная строка пары.

Для каждого показателя суммируются percentDelta всех генов, ограничивается
единый множитель, после него прибавляются flatDelta, применяется минимум и
HALF_UP. База берётся только из исходных видов по шести HERITAGE-копиям.
Историческое имя и справочные baseStats гибридов не участвуют в формуле.

Вычисление использует BigDecimal без промежуточного округления. Взвешенная база
хранится внутри расчёта как числитель с общим знаменателем шесть; flatDelta и
минимум приводятся к тому же знаменателю. Единственное деление с округлением
происходит в конце: скорость — два знака, остальные шесть статов — целые.
Так смесь 1:5 не превращает точную половину в число чуть меньше неё из-за
приближённого десятичного представления 1/6.

Потенциал не включает возраст, XP/обучение, роль, состояние или экипировку.
Он не применяется к ECS и не изменяет переданный геном.

## Проявленные состояния и магия

Внутренний результат содержит точные ссылки, историческую/effective форму,
счёт HERITAGE-копий, семь статов, состояние каждого trait-гена, визуальные токены,
именованные utility-модификаторы и необязательный `innateSpellPotential`.

Визуальные токены берутся только из применимых правил: отсутствие рогов при
`none|none` сохраняется явно как `horns=none`; крылья/клюв появляются в результате
Крылатых. Для других семейств не придумываются привязки этих слотов.
Скрытое носительство не меняет визуальный токен рецессивного признака и остаётся
в исходном геноме. Знания конкретного игрока — отдельный будущий контракт.

Utility сохраняет именованные числа отдельно от физиологических статов:
например, расход сил атаки не уменьшает генетическую выносливость.
Применение этих модификаторов к игровым событиям относится к последующим этапам.

`ARCANA=awake` выбирает максимум один потенциальный spell ID по проявленному
ELEMENT. `quiet` даёт пустой потенциал. Это не разрешение колдовать:
возрастной/учебный допуск, feature flags, активные слоты, цели, затраты и cooldown
проверяются будущим игровым слоем. [Выбор signature passive](stage-1-v07-signature-passives.md)
по effective форме/выбранной роли реализован отдельно; численные эффекты пока
не исполняются, описания из контента не парсятся как код.

Результат является полным внутренним генетическим расчётом, **не публичным
паспортом**. Отправлять его целиком клиенту до реализации модели знаний нельзя.
Символические токены также не доказывают наличие моделей: возрастной manifest,
проверка обязательных `(rigId, slot, state, age)` bindings и клиентская приёмка
остаются отдельной работой 1/1V. Неподдержанные ассеты не дают права повторить RNG.

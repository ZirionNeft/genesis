запуск. Временная Remote JVM configuration и несуспендирующие logpoints — локальные
средства наблюдения; для использования `/genesiscompat` debugger не требуется.

В исходном сценарии игрок должен был войти клиентом **0.7.2** на `127.0.0.1:5520`,
наводится на ванильного NPC в пределах восьми блоков и дважды выполняет
`/genesiscompat`. Теперь используется клиент/сервер **0.7.4** по ссылке выше.
Требуется `genesis.prototype.compatibility`.
Команда только читает существующие компоненты; геном, кандидат и ownership
не создаются. Приручение видов по этим результатам пока не включается.

Проверка первого осмотра ещё не состоялась; UUID/role/Ref/thread значения
в отчёт не подставлены. При отсутствии подходящего NPC отдельный технический
субъект должен оставаться тестовым, без первооткрытий или игровых наград.
Смена роли и рестарт требуют отдельного сравнения до/после и не считаются
пройденными по одному codec-тесту или успешному запуску.

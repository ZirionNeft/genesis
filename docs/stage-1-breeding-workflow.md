## Решение D11: воспроизводимые потоки

`GenerationSeed.SCHEME_VERSION=1`, алгоритм `genesis:generation_sha256_v1`.
Один signed i64 generation seed принадлежит одной попытке. Его выдача, связь
с `breedingEventId` и защита от перебора/повторной выдачи относятся к 2A.
Codec seed — отдельный внутренний формат, он не меняет GEN1 wire/schema v1.

Байтовый codec: ровно 16 байт, big-endian:

| Поле | Размер | Значение |
| --- | --- | --- |
| magic | 4 | ASCII `GENS`, hex `47454e53` |
| scheme version | i32 | `1` |
| generation seed | i64 | Все 64 бита, включая знак |

Другие magic/версии, усечённые и дополнительные байты отклоняются.
Формат не имеет альтернативных представлений одного seed.

Получение потока:

```text
digest = SHA-256(ASCII("genesis:rng\0") || encode(generationSeed) || ASCII(label))
streamSeed = signed_big_endian_i64(digest[0:8])
```

`\0` здесь — один нулевой байт. Метки фиксированы, не зависят от enum ordinal,
Java hashCode, порядка регистрации и расхода других потоков:

| label | Потребитель | Контракт v1 |
| --- | --- | --- |
| `attempt` | Успех попытки | Новый `java.util.Random(streamSeed)`, один `nextDouble()` |
| `inheritance` | Передача аллелей | `SeededAlleleRandom`, существующий inheritance algorithm v1 |
| `mutation` | Одна de novo мутация | `SeededMutationRandom`, существующий mutation algorithm v1 |
| `frailty` | Врождённая ослабленность | `SeededFrailtyRandom`, существующий inbreeding algorithm v1 |
| `cosmetic` | Внешние косметические решения | Сам i64 `streamSeed`, сохраняется как cosmetic seed |

Java Random использует 48-битное состояние; SHA-256 учитывает все 64 бита
исходного seed до создания каждого RNG. Это детерминированное разделение
псевдослучайных потоков, без обещания уникальности/криптографической защиты.
При изменении алгоритма/меток/байтов требуется новая версия, без тихого fallback.

Повтор расчёта создаёт новые локальные RNG от тех же seed. Нет общей изменяемой
случайности, счётчиков или зависимости от порядка соседних расчётов. Cosmetic
seed не расходуется успехом, наследованием, мутацией или ослабленностью.

Для seed `42`, codec `47454e5300000001000000000000002a`:

| Поток | streamSeed | Первый draw / результат |
| --- | --- | --- |
| attempt | -1788674043282771009 | 0.5402573282344997 |
| inheritance | 8455894584901405955 | `000101111110111000100010` — 24 canonical copy choices |
| mutation | 6829040405943199912 | 0.6135200664623726 |
| frailty | -7329418783055360100 | 0.8660122488623799 |
| cosmetic | 3213433986526642893 | Этот i64 сохраняется без дополнительного draw |

Независимые Python `struct`/`hashlib` и реализация LCG создают
[шесть векторов](../src/test/resources/generation-seed-v1-vector.properties):
0, 42, -1, оба signed i64 предела и `42 + 2^48`.
Генератор: [generation_seed_vector.py](../src/test/python/generation_seed_vector.py).
Проверка fixture не требует Hytale или сторонних Python-библиотек.

## Чистый workflow v1

`BreedingWorkflow` получает frozen каталог, версионируемые правила мутаций
и обязательные зависимости доверенного контентного профиля. Request содержит
immutable snapshots двух родителей с разными UUID, их ancestry/extension bytes,
родословную, глубину расчёта, готовность/среду/Гармонию и generation seed.
Policy отдельно фиксирует совместимость, инбридинг и вероятности мутаций.

Порядок `calculate`:

1. Проверить разные UUID, совместимость family/rig/species и оба полных генома.
2. Проверить точный genetics ruleset правил мутаций и зависимости расширений.
3. Рассчитать родство и получить Allowed от InbreedingRules. Rejected и
   Indeterminate завершают попытку до RNG; неполные данные не превращаются в ноль.
4. Рассчитать `clamp(C * R_A * R_B * E * Q, 0, 0.95)`.
5. Сделать ровно один attempt draw, в том числе при нулевом шансе.
   Успех только при `draw < chance`; равенство означает неудачу.
6. Только при успехе: один вызов наследования (24 выбора), один вызов мутации,
   отдельный расчёт ослабленности, усреднение ancestry и выделенный cosmetic seed.

Результаты: `Rejected(reason)` без RNG, `Failed(chance, draw)` без потомка
или `Conceived` с исходным унаследованным геномом, результатом мутации,
конечным геномом, ancestry, оценкой родства, frailty и cosmetic seed.
При нулевом риске frailty draw не нужен. Mutation SKIP сохраняет геном
и причину; повторов/нормализации на существующий контент нет.

Поддержка наследования payload расширений ещё отсутствует. Поэтому **любые**
payload обоих родителей, включая распознанную необязательную косметику,
и непустой список обязательных зависимостей профиля дают
`UNSUPPORTED_EXTENSIONS` до первого draw. Это консервативное ограничение
этого workflow, а не изменение разрешения GEN1 preflight: codec/registry
по-прежнему умеют сохранять и проверять opaque. Удаление payload из запроса
не обходит обязательную зависимость профиля. Исходные bytes не меняются.
Будущий загрузчик должен передавать авторитетные зависимости профиля и полные
snapshots; методы ядра не аутентифицируют вызывающий код.

## Границы этапов

`Conceived` — генетический кандидат, **не** созданная Искра/NPC и не commit.
Workflow не выбирает вид/архетип, не строит GEN1 потомка и не утверждает
доступность всех визуальных выходов draft Клыкастых. До игрового доступа
требуется полное покрытие контентного профиля разрешёнными ассетами/эффектами.
Неподдерживаемая внешность не даёт права перебросить геном или seed.

2A/2B добавят controller/owner/permissions, готовность/возраст/cooldown,
ограниченные Before validators, резервирование пары/ресурсов/места,
атомарную запись результата и события, одну Искру и доставку After-событий.
Повтор функции воспроизводит кандидат, но сам по себе **не** предотвращает
повторную выдачу предмета. Durable идемпотентность требует решения D02.

Для replay недостаточно одного seed: нужны те же родители в том же порядке,
ancestry/родословная и глубина, условия, frozen каталог и версии genetics/
mutation/workflow/seed algorithms, dependency-профиль и весь snapshot Policy.
Выбор хранилища и формат полного журнала попытки не приняты этим пакетом.

## Проверки

16 новых тестов: канонический codec/ошибки версий и длин, независимые векторы,
полные 64 входных бита, расход изолированных RNG, повтор после соседнего расчёта,
точные границы успеха, отсутствие детских RNG при отказе/неудаче,
однократность наследования/мутации, сохранность opaque, обязательные зависимости,
частичная/запрещённая родословная и отсутствие переброса при mutation SKIP.

100 000 попыток с generation seed 0…99 999, два синтетических гетерозиготных
родителя с phi=0.25: успех 70%, условное FRAME-наследование 25/50/25 и отдельная
ослабленность 25% среди успешных результатов. Каждое сравнение использует
допуск шесть биномиальных sigma; настройки frailty здесь тестовые.

`./gradlew build verifyPluginJar --console=plain`: **137 PASS**, без
failures/errors/skipped. Все **46** файлов core отдельно компилируются
`javac --release 25` с пустым внешним classpath. Python fixture воспроизводится
побайтово. Отчёт тестов: `build/reports/tests/test/index.html`.

## Как вести план

- Статусы: TODO / IN_PROGRESS / BLOCKED / DONE. DONE требует даты и свидетельств;
  игровое поведение подтверждается сервером/клиентом, не только компиляцией.
- Сохранять исторические результаты с их ограничениями; не превращать новую
  спецификацию или JSON с `UNVERIFIED` в свидетельство готового API/ассета.
- Серверные значения брать из Server Config, определения — из каталогов.
  Числа являются стартовым балансом; изменения правил/хешей требуют явных версий.
- Решения с последствиями для генетики/сохранений/форматов фиксировать здесь
  и в профильных документах. Исходный GDD без прямого поручения не менять.

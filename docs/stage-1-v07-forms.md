## Историческая форма

[HybridGraph](../src/main/java/dev/ifelse/zirion/genesis/core/content/v2/HybridGraph.java)
получает определения из нормативного graph v1 через Java CatalogLoader.
В immutable `CatalogBundle` теперь находятся исполняемый граф, семейные схемы
v2 и прежние исходные snapshots. Второй таблицы форм/пар в production Java нет.

В графе четыре семейства, три исходных вида и семь непустых подмножеств корней
на семейство: 28 форм и 112 неупорядоченных пар, включая одинаковые формы.
Пара симметрична: A×B и B×A выбирают один результат. Исторические корни ребёнка
равны объединению корней родителей; потеря генетической линии их не сокращает.

`FormIdentity` содержит точный ID/version/SHA-256 графа и ID исторической формы.
`historicalChild` проверяет обе ссылки и ищет **явную** пару из каталога.
Межгрупповая/неизвестная пара, неизвестная форма или другой fingerprint дают отказ.
Этот метод вычисляет только исторические метаданные; он не проверяет права,
разные creatureId, возраст, readiness, ресурсы или допустимость игрового рождения.

При freeze проверяются уникальные семейства/founders/формы/наборы корней,
совместимость rig и семейства, все семь подмножеств, полный набор явных пар и
union результата. Пропущенная пара или неоднозначные корни дают отказ;
создания нового узла по похожему набору корней нет. Политика источника обязана
быть `explicit-edges-only`. Расширения графа с новыми ID требуют отдельного контракта.

## Генетически проявленная форма

[FormResolver](../src/main/java/dev/ifelse/zirion/genesis/core/content/v2/FormResolver.java)
работает со снимками графа и семейных схем. `resolve(identity, genome)`:

1. Проверяет точную ссылку графа и существование исторической формы.
2. Проверяет весь геном по соответствующей семейной схеме, включая ID/version/
   SHA-256, полный набор генов и варианты каждого гена.
3. Считает все шесть HERITAGE-копий; каждый вид с положительным числом копий
   входит в генетическую поддержку. Порога большинства или доминирования нет.
4. Проверяет, что поддержка входит в исторические корни, и находит её точный
   зарегистрированный узел. Возвращает историческую форму, `effectiveSignatureForm`
   и неизменяемые положительные числа копий с суммой шесть.

Волк×лисица даёт исторического волколиса с составом 3:3. При обратном
скрещивании с лисицей возможны шесть копий лисицы: историческая форма остаётся
волколисом, `effectiveSignatureForm` становится лисицей. При дальнейшем
скрещивании с гиеной историческая форма — Трёхклык, а генетическая поддержка
может соответствовать лисогиене. Одна оставшаяся копия волка сохраняет волка
в поддержке; её нельзя округлить до нуля.

Здесь нет RNG, переписывания генома или замены HERITAGE родословной.
Полученный узел предназначен для будущего разрешения signature passives;
выбранная роль и её допуски ещё должны проверяться отдельно. Узел не является
породой игрока и не задаёт фиксированную базу статов гибрида.
